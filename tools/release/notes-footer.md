## Credits

274bot is built on **[rs2b0t](https://github.com/rs2b2t/rs2b0t)**. Its interface is modelled on rs2b0t's, it keeps rs2b0t's script API so the rs2b0t catalog runs here, our quest Paths started from its AIOQuester, and parts of our game data come from it. Thank you to [everyone who has contributed to rs2b0t](https://github.com/rs2b2t/rs2b0t/graphs/contributors).

The Quester also owes a lot to Liza Carvelli's Questionable, a quest-automation plugin for [Dalamud](https://github.com/goatcorp/Dalamud).

274bot builds on [Lost City](https://github.com/LostCityRS), the open 2004-era engine, content and client work, and on the [Fairy Ring](https://github.com/Fairy-Ring/FR-client-rust) Rust client. Licenses are in `NOTICE.md` in every package.
