# Latency cohort producer report

The host now exposes `host::responsiveness_cohort`, an additive process-local producer journal. `begin(Boundaries, capacity)` is explicit Rust opt-in and accepts one immutable half-open window `[start_mono_ns, end_mono_ns)` plus a finite tail. A second active cohort, malformed boundaries, stale/overlapping boundaries, and post-finalization reuse are rejected. `acknowledge_producers_closed()` is the required nonblocking synchronization barrier: its caller must first stop/join every producer generation that can publish cohort events; `finalize` refuses to run without that acknowledgement.

Each accepted decode or focused input start receives `EventId { slot_id, generation, sequence, start_mono_ns, surface }`. Existing responsiveness entrypoints attach the identity to their bounded pending records. Dispatch/present/draw completion, cancellation, and teardown loss publish `EventRecord` or `LossReceipt`; capacity, missing identity, malformed timestamps, late completion, generation mismatch, and incomplete tail closure are explicit and make the terminal summary unavailable. Starts before/at-or-after the fixed window never enter the journal; included completions may arrive through `end + tail` only.

Storage is bounded by the caller-selected capacity (default 512): pending identities and terminal journal entries share the same bound. The journal has its own monotonic extraction cursor, independent of event identity sequence, so a long-pending early event cannot wedge later terminal records. `extract_since(cursor)` drains all later journal entries in publication order; a full journal fails closed and increments the serialized `journal_overflow_n` gap counter rather than silently advancing or retaining an unbounded loss vector. Extraction returns schema version, immutable boundaries, ordered records, loss receipts, cursor, loss count, overflow-gap count, and terminal state. `finalize` is nonblocking and returns `TerminalSummary`; before the tail or before the producer barrier it refuses to finalize, and at the tail it records each unresolved identity as `Incomplete` and fails closed.

Legacy aggregate counters, histograms, pending gauges, queue capacities, and disabled fast paths remain unchanged. Input generation lookup is gated by the cohort atomic, so disabled input does not take the new registry lookup. Existing host entrypoint tests still pass; focused cohort tests cover window/tail membership, extraction order with an early pending event, capacity loss, and timeout/incomplete behavior.

Handoff contract: host-play must call `begin` with its already-recorded observe boundaries, call the existing producer entrypoints normally, stop/join or otherwise synchronize all event producers, call `acknowledge_producers_closed()`, periodically call `extract_since(cursor)`, and call `finalize(end + tail)`. Readers must require `schema_version == 1`, validate every identity and boundary, preserve loss receipts and `loss_count`, and make unavailable summaries ineligible. Existing binaries do not emit this schema.
