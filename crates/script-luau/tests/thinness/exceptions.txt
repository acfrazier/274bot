# Rule T6 (LUAU-DESIGN-1114/design-r3.md 7.4): a Request or Await row with no
# JS API v2 counterpart needs one line here, `path: reason`.
wait: the wait for the next game tick queues no request; JS v2 gets the same pause from an awaited Promise (design-r3.md 7.4 rule T6 names it as the one entry at the start).
bank.openNearest: the typed native plan can select and walk to a world bank; JS v2 open-booth needs a selected booth and has different scope.
bank.depositAll: the typed native plan deposits every bankable backpack item; JS v2 deposit names one item.
interact.held: the native binding requires an exact slot and item id; JS v2 held accepts only a name and action.
interact.loc: this generic loc action has no matching JS v2 request; open-booth is bank-only.
interact.npc: JS v2 has no typed NPC action request.
interact.obj: JS v2 has no typed ground-item request with an exact tile and id.
interact.player: JS v2 has no typed player action request.
